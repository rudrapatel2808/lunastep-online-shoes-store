# LunaStep Design System

A polished glassmorphism design system demo for footwear and inventory experiences. The project is separated into `index.html`, `styles.css`, and `script.js`.

## Files

- `index.html` — main application markup
- `styles.css` — layout, typography, and visual design
- `script.js` — tabs, interaction effects, dynamic data, and animation logic

## Run locally

Open `index.html` in a browser to preview the LunaStep design system.
